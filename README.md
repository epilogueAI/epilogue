## What is ÉPILOGUE?

**ÉPILOGUE** is an AI agent skill focused on **closing chapters cleanly**.

It helps you:

- Plan and execute **clean portfolio exits**
- Create **legacy vaults** and hand-off plans
- Generate **technical post-mortems** + **narrative epilogues**
- Archive trading history, fees, and agent memory before the end

Designed for the Bankr ecosystem. Safety-first: read-only by default, every irreversible action requires explicit confirmation.

## Safety

ÉPILOGUE is built with strong guardrails:

- Starts in **read-only** mode
- Never executes transfers, swaps, or closes without clear confirmation
- Never invents data
- Always shows a preview before any irreversible action

See `references/safety-rules.md` for the full ruleset.
