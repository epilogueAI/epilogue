# Report Templates

Use these structures when generating final outputs. Adapt length and detail to the actual data available. Never pad with invented content.

---

## Template A — Exit Report

```
ÉPILOGUE — Exit Report
Date: [ISO date]
Scope: [Full portfolio / specific chains / specific positions]
Status: [Completed / Partial / Stopped by user]

1. Summary
   - Starting estimated value: …
   - Actions completed: …
   - Final estimated value / destination: …
   - Residual items left intentionally: …

2. Stages Executed
   Stage A — Residual Claims
   - [list of claims and results]

   Stage B — Risk Reduction
   - [list]

   Stage C — Liquid Exits
   - [list]

   (Add stages as used)

3. Notable Events or Issues
   - [any failures, high slippage, skipped items, etc.]

4. Remaining Positions (if any)
   - [list with reason they were kept]

5. Files / Archives Created
   - [links or filenames]

Closing line: Chapter closed.
```

## Template B — Technical Post-Mortem

```
ÉPILOGUE — Technical Post-Mortem
Subject: [Token / Agent / Wallet / Period]
Generated: [ISO date]

1. Identity
   - Name / address / chain
   - Deployment or start date
   - Relevant identifiers

2. Timeline of Key Events
   - [date] — [event]
   - …

3. Performance Snapshot
   - Peak metrics (volume, mcap, fees, etc.)
   - Final state
   - Fees / value captured (if applicable)

4. What Worked (observable)
   - …

5. Turning Points & Challenges (observable)
   - …

6. Residual Value
   - …

7. Data Gaps & Open Questions
   - …

End of technical record.
```

---

## Template C — Narrative Epilogue

(No rigid headings inside the final text. Write as a continuous short piece.)

Guidance:
- 300–700 words unless the user requests otherwise.
- Open with context or a quiet image.
- Acknowledge intention and outcome without cruelty.
- Close with a sense of completion.

Example closing sentences (adapt freely):
- “The chapter is closed.”
- “What remains is the record.”
- “This is where this story rests.”

---

## Template D — Combined Final Chapter

```
ÉPILOGUE — Final Chapter
Subject: …
Date: …

Part I — Technical Record
[Insert Template B content]

Part II — Narrative Epilogue
[Insert the narrative text]

Part III — Exit Summary (if applicable)
[Short version of Template A]

Chapter closed.
```

---

## Notes on Usage

- Always fill only the sections for which real data exists.
- If a section would be empty, omit it rather than writing “N/A” repeatedly.
- Offer the user the choice of which template(s) they want before generating long reports.
- After generation, offer to save the report as a file in the user’s Bankr filesystem.
